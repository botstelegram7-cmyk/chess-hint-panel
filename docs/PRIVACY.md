# Privacy

Chess Hint Panel does not collect, store or transmit any data.

* **No internet permission** — the app literally cannot send anything anywhere. The engine,
  the screen reader and the game tracker all run on your phone.
* **Screen capture** uses Android's own MediaProjection API, only while you have the panel
  running, only to find the chess board on your screen.
* **No account, no ads, no analytics, no third-party SDKs.**
* The only file the app writes is a small local log (`panel-log.txt` inside the app's private
  storage) with error messages and your device model, so a problem can be diagnosed. You can
  clear it from the Diagnostics card, and it never leaves the phone unless you press **Share log**.
* Removing the app removes everything it stored.
